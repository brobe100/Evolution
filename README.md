# Evolution

A tiny browser game inspired by the description from a child:

- Create a planet and choose a diet: carnivore, herbivore, or omnivore.
- Begin on a world creation screen with multiple saved worlds.
- Start in a watery planet where an asteroid cracks open a tiny cell.
- Swim through the ocean and eat smaller creatures while avoiding larger ones.
- Herbivores gather floating vegetation.
- Use the mating call to open the Evolution Hub, but only when you are not in battle.

## How to run

Open the project folder in a web browser, then launch the game by opening `index.html`.

If you want to serve it locally instead:

```bash
cd "c:\Users\brobe\OneDrive\Desktop\Noah's Creations\Video Games\Evolution"
python -m http.server 8000
```

Then visit http://localhost:8000 in your browser.
